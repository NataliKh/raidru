# RaidRU 0.5 — реальные карты арен

Русский визуальный планировщик рейдов World of Warcraft.

## Главное в этой сборке

- Все 8 арен The Venomous Abyss заменены на реальные top-down подложки,
  выгруженные пользователем через **RaidPlan → Download image**.
- Карты оптимизированы в WebP без изменения исходной геометрии 1231×692.
- Координаты игроков, зон, стрелок, конусов и маршрутов накладываются прямо на карту.
- У каждой сцены есть настройки:
  - масштаб карты;
  - сдвиг по X;
  - сдвиг по Y;
  - затемнение.
- Сохраняются сцены, эффекты, маршруты, таймлайн, настройки карты и состав.
- В проигрывателе остаётся плавное перемещение между ключевыми кадрами.
- На главной используются превью реальных арен.
- Добавлена публичная атрибуция:
  `Maps/raid planning resources: RaidPlan.io`.
