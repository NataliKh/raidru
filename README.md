# RaidRU 0.5.2

Исправленная сборка с эталонными 8 картами арен.

Порядок:
1. Нек'зали
2. Погребённые часовые
3. Вашник Злокачественный
4. Потерянные исследователи
5. Сззорак
6. Двойные Клыки
7. Спиральный алтарь
8. Ула'тек

Исправления:
- карта показывается целиком (`object-fit: contain`), без обрезки;
- удалены остаточные схематичные фоновые слои;
- исправлен порядок Вашника и Потерянных исследователей;
- новый cache key для GitHub Pages;
- однократная миграция сбрасывает только старые несовместимые сцены;
- прогресс, заметки, избранное, состав и таймлайн сохраняются;
- атрибуция RaidPlan сохранена в подвале.
