# RaidRU 0.3

Статическая версия для GitHub Pages.

## Новое
- визуальный проигрыватель боя;
- плавные переходы токенов между сценами;
- эффекты на арене: опасные зоны, soak, стрелки, конусы и линии;
- редактор таймлайна с привязкой события к сцене;
- автоматическое проигрывание боя по времени;
- экспорт/импорт/шаринг включает сцены, эффекты и таймлайн;
- совместимость с данными RaidRU 0.2 через тот же localStorage.

## GitHub Pages
Загрузить все файлы из архива в корень репозитория и сделать Commit. GitHub Pages обновится автоматически.

## Управление эффектами
- перетаскивание — позиция;
- двойной клик — подпись;
- ПКМ — удалить;
- колесо мыши — размер;
- Shift + колесо — поворот.
