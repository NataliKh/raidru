# RaidRU 0.7.11 — Clean Authored Scenarios

Исправление касается именно уже готовых встроенных сценариев.

## Что было неправильно
В старых сохранённых сценах могли одновременно существовать:
- encounter-иконка объекта в новой позиции;
- старый эффект/круг объекта в прежней позиции;
- старая текстовая подпись.

Из-за этого, например, у Ула'тек иконки яиц были уже откалиброваны,
но четыре красных круга «Яйцо» оставались в старых углах.

## Что сделано
- встроенные сцены теперь мигрируют на актуальные authored presets целиком;
- обновляются позиции, effects и routes, а не только токены;
- пользовательские отдельные сцены по другим именам не трогаются;
- реальный состав и вручную добавленные encounter-объекты сохраняются;
- пользовательские настройки zoom/смещения/затемнения карты сохраняются;
- после миграции повторно запускается hard arena mask.

### Ула'тек
- удалены четыре дублирующих красных круга «Яйцо»;
- яйца остаются только как игровые иконки;
- из сцены «Едкие волны» убраны старые круги «Не задеть яйцо»;
- из сцены возврата убран старый круг «Сохраняем яйцо»;
- на P3 удалён лишний текстовый маркер SAFE — safe-сектор показывает зелёная область;
- подписи механик оставлены только там, где они объясняют действие.

### Tooltip
У encounter-иконок больше нет стандартного белого browser tooltip.
При наведении появляется компактная тёмная подсказка RaidRU.

После обновления достаточно один раз открыть сайт — встроенные сцены
мигрируют автоматически.
