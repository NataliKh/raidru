# RaidRU 0.8.8 — единая карта рейда 2608 + The Lost Explorers Heroic

## Исправление архитектуры карт

- Основной принцип: **один большой файл карты рейда `2608-map`**, а каждый босс показывает свой участок через viewport.

- Пользовательские `Масштаб / Сдвиг X / Сдвиг Y` применяются поверх базового viewport босса.
- Для боссов 4–8 точные участки 2608 будут добавляться после их Heroic replay, без выдумывания координат.

## Миграция

При первом открытии 0.8 встроенные Vashnik-сцены и таймлайн обновляются автоматически. Пользовательские отдельные сцены и roster/class tokens стараемся сохранить; старая калибровка карты Vashnik не переносится, потому что подложка изменилась.

## 0.8.3 — свободные подписи механик

- Любую подпись эффекта/механики на арене можно перетаскивать независимо от самого объекта.
- Позиция хранится как смещение от эффекта и сохраняется в плане/localStorage.
- Shift при перетаскивании фиксирует движение по одной оси.
- Двойной клик или ПКМ по подписи возвращает автоматическое размещение.
- Для вынесенных вручную подписей рисуется пунктирная линия к объекту.
- В дополнительных инструментах появились «Развести подписи» и «Сбросить подписи».
- Автоматическая раскладка получила дополнительные диагональные позиции и более строгую проверку пересечений.
