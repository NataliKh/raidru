# RaidRU 0.8.10 — Map architecture fix

## Новое в 0.8.10

- Удалена глобальная привязка боссов к `2608-map`.
- Добавлены источники карт `2606`, `2607`, `2608`, `2609` и конфигурация `bossMaps: { mapId, viewport }`.
- Heroic mapID: Nek’zali → 2606; Entombed Sentinels/Vashnik → 2608; Lost Explorers/Sszorak → 2609; Twin Fangs → 2607.
- Lost Explorers и Sszorak откалиброваны на разные комнаты `2609-map`; Twin Fangs перенесены на треугольную арену Pit of Fangs из `2607-map`.
- Авторские сцены этих трёх боссов пересчитаны под новые локальные координаты; пользовательские сцены и ростер миграцией не удаляются.
- Перетаскиваемые подписи механик, линии к вынесенным подписям, «Развести подписи» и «Сбросить подписи» сохранены.
- Вашник не перекалибровывался и сохраняет утверждённый viewport.
- Coiled Altar и Ula’tek по-прежнему не получают новый mapID без Heroic Replay.
