# RaidRU 0.7.7 — Scenario Encounter Icons

## Главное изменение

Игровые иконки теперь встроены непосредственно в уже готовые тактические
сценарии планировщика.

Текстовые служебные токены автоматически получают визуальные иконки:
- боссы;
- адды;
- Колодец душ;
- слизень;
- источники;
- рыба / Вознесение;
- отродья;
- сгустки;
- ужасы;
- щит;
- яйца;
- стражи.

Игроки T/H/M/R, игроки из состава и стандартные рейдовые метки при этом
остаются отдельными типами объектов.

### Важное поведение

Обогащение выполняется в `normalizeScene()`, поэтому работает не только с
новыми пресетами, но и с уже сохранёнными сценами из localStorage.
Пользовательские координаты не сбрасываются.

Все encounter assets хранятся локально:
`assets/palette/encounter/game/`.

RaidRU — неофициальный фан-проект World of Warcraft.
