# RaidRU 0.7.5 — Encounter Library

## Новое

В планировщике появилась библиотека иконок, похожая по логике на RaidPlan/Raidstrats:

- вкладка **БОЙ** — иконки текущего босса, важных существ, объектов и ключевых механик;
- вкладка **ПОИСК ИКОНОК** — поиск по библиотеке всех восьми боссов;
- все элементы поддерживают Drag & Drop и Click to Spawn;
- существа/боссы отображаются круглыми токенами, способности и предметы — квадратными;
- токены можно перетаскивать, переименовывать и удалять как обычные элементы плана;
- сохраняется привязка к допустимой геометрии арены из 0.7.4.

## Encounter Journal

Для восьми боссов используются локально сохранённые изображения Encounter Journal, опубликованные Wowhead/Zamimg. Остальные символы механик — локальные графические ассеты RaidRU.
