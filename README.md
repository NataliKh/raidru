# RaidRU 0.5

Русский визуальный планировщик рейдов World of Warcraft.

## Новое в 0.5

- Более реалистичный top-down стиль арен: каменные полы, стены, проходы, лестницы, ниши и объёмные элементы.
- Особенно переработана арена Нек'зали по геометрии, близкой к реальному рейдовому плану: центральный зал, колодец, саркофаги, вход/выход и боковые ниши.
- Слой карты затемняется отдельно, чтобы цветные тактические объекты оставались читаемыми.
- Редактор маршрутов игрока внутри сцены.
- Можно выбрать игрока, включить режим маршрута и поставить любое количество промежуточных точек кликом по арене.
- Точки маршрута перетаскиваются и удаляются ПКМ.
- Маршрут автоматически соединяется с позицией игрока в следующем ключевом кадре.
- Проигрыватель двигает игрока через промежуточные точки, а не просто по прямой между сценами.
- Маршруты сохраняются в localStorage, экспорте, backup и ссылках «Поделиться».

## GitHub Pages

Загрузите содержимое архива в корень репозитория с заменой старых файлов и сделайте commit.

Если браузер показывает старую версию, сделайте Ctrl+F5. Service Worker использует cache key `raidru-v05`.
