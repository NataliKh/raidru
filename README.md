# RaidRU 0.7.6 — RaidPlan Encounter Icons

В 0.7.6 временные самодельные encounter-механики заменены игровыми иконками,
которые видны в присланном пользователем скриншоте Encounter-панели RaidPlan.

## Что изменилось

- из скриншота локально извлечено:
  - 12 круглых NPC/object icons;
  - 43 квадратных ability icons;
- все файлы лежат внутри RaidRU:
  `assets/palette/encounter/raidplan/`;
- основные mechanic icons RaidRU теперь используют этот реальный WoW-набор;
- для Ула'тек Encounter-панель использует соответствующие иконки из RaidPlan;
- ниже именованных элементов Ула'тек доступен полный набор из 55 видимых иконок;
- весь pack также доступен через «ПОИСК ИКОНОК»;
- drag & drop / click-to-spawn работают как раньше;
- никакого hotlink: эти иконки входят в архив проекта.

## Важно

Полный pack был извлечён из скриншота RaidPlan для boss=8 (Ула'тек).
Поэтому точное сопоставление всех иконок с названиями механик остальных семи
боссов в этой версии не заявляется. Однако временные абстрактные mechanic
icons уже заменены на реальные игровые WoW-иконки.

Для идеально точного Encounter-набора каждого босса можно аналогично добавить
скриншоты RaidPlan boss=1..7 или сопоставить spell/NPC ID через журнал боя/API.
