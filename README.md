# RaidRU 0.8.11 — NSRT voice notes

## Новое в 0.8.11

- В разделе «Заметки» появился готовый импорт Northern Sky Raid Tools с русской TTS-озвучкой.
- Голосовые заметки собраны для семи боссов с заполненными Heroic PTR BossTimelines: Нек'зали, Погребённые часовые, Вашник, Потерянные исследователи, Сззорак, Двойные Клыки и Спиральный алтарь.
- Основа таймингов — Heroic BossTimelines Midnight Season 2 из NSRT; фазовые времена переводятся в абсолютные секунды от пула и фильтруются на границе следующей фазы.
- Ключевые механики получают короткий общий TTS-вызов примерно за 3 секунды.
- Перед выбранными крупными окнами рейдового урона добавлен отдельный `tag:healer` с `TTSTimer:5` и русской фразой для подготовки хила.
- Голосовые вызовы намеренно не дублируют каждую мелкую способность: это «рейд-лидерская» заметка, а не второй boss-mod.
- Ула'тек пока не получает готовый голосовой импорт: его текущий Heroic BossTimeline в NSRT содержит длительность/фазы, но массив способностей пока пуст.
- Карты, viewport, сцены, ростер, пользовательские подписи и миграции 0.8.10 не изменялись.

## Карты

Архитектура mapID/viewport из 0.8.10 сохранена без изменений.
