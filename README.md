# RaidRU 0.7.10 — Hard Arena Masks

В этой версии геометрия арены проверяется по реальному доступному полу, а не
только по общему прямоугольнику изображения.

## Что изменилось

- для каждого босса задана более консервативная walkable-mask;
- у Двойных Клыков центральная пустота исключена из доступной зоны;
- для разрушенной P3 Ула'тек заданы четыре отдельные физические платформы;
- встроенная P3-тактика закреплена за правым нижним safe-сегментом;
- проверяется не только центр токена, но и его видимый радиус;
- танки, хилы, ДД, классовые иконки, боссы, encounter-объекты и рейдовые
  метки не могут частично висеть над ядом/пустотой при включённой маске;
- маршруты игроков тоже автоматически остаются на доступной площадке;
- автоматическая расстановка состава проходит через ту же геометрию;
- уже сохранённые локальные сцены мигрируются один раз: перемещаются только
  точки, которые не проходят новую проверку геометрии.
