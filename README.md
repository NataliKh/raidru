# RaidRU 0.4

Русский визуальный планировщик рейдов World of Warcraft.

## Новое в 0.4

- Оригинальные фоновые схемы арен для всех 8 боссов «Ядовитой бездны».
- У каждой арены собственная геометрия: колодец и саркофаги, разделённая комната, источники, круглая ветровая платформа, алтарь, яйца и т.п.
- Сцены теперь оформлены как **ключевые кадры** и показывают привязанный тайм таймлайна.
- Переключаемые **траектории движения** игроков к следующему ключевому кадру.
- Проигрыватель показывает следующий кадр и номер текущего кадра.
- Перемещение токенов использует длительность сцены для более плавной анимации.
- Легенда ролей и траекторий под проигрывателем.
- Экспорт/backup обновлены до формата 0.4.

Карты арен — самостоятельные схематические иллюстрации RaidRU, а не игровые текстуры. Это позволяет свободно редактировать их и сохранять хорошую читаемость механик.

## GitHub Pages

Загрузите содержимое архива в корень репозитория и замените старые файлы. После commit GitHub Pages обновится автоматически.

Если браузер показывает старую версию, сделайте Ctrl+F5. Service Worker использует новый cache key `raidru-v04`.
