# RaidRU v0.8.12

Русскоязычный planner-first планировщик рейда WoW Midnight Season 2 — The Venomous Abyss.

## Новое в 0.8.12 — RaidPlan Import

- Кнопка **⇄ RaidPlan** в верхней панели.
- Импорт публичной ссылки `https://raidplan.io/plan/...` (если RaidPlan разрешает cross-origin чтение страницы).
- Резервный импорт сырого RaidPlan JSON / JSON-файла.
- `tools/raidplan-browser-export.js` — fallback Snippet для страницы RaidPlan, когда CORS блокирует прямой URL-импорт.
- Отдельный адаптер `raidplan-importer.js`, чтобы будущие изменения формата/API RaidPlan не затрагивали основную логику Planner.
- Поддерживаются `steps/scenes/pages/slides/frames` и вложенные `objects/elements/items/layers`.
- Переносятся игроки/роли/классы, raid markers, текст, зоны/soak, линии, стрелки и cone.
- Polygon временно аппроксимируется ограничивающей зоной и отмечается в отчёте.
- Координаты распознаются как 0..1, проценты, canvas pixels или true-scale/произвольная система с сохранением пропорций.
- По умолчанию импортированные сцены **добавляются** к текущему плану. Режим замены делает автоматическую резервную копию.
- После импорта доступно восстановление последней резервной копии для босса.

## Важно про RaidPlan

На 13 августа 2026 RaidPlan сообщает, что документация developer integration будет добавлена позднее. Поэтому транспорт импорта изолирован от основного Planner, а fallback Browser Exporter читает только данные, уже загруженные в открытой вкладке публичного RaidPlan.

## Сохранено из предыдущих версий

- Heroic-only тактики и Planner-first архитектура.
- `raidMaps` / `bossMaps` с mapID 2606/2607/2608/2609.
- Перетаскиваемые подписи механик, линии к вынесенным подписям, «Развести подписи» и «Сбросить подписи».
- Ростер, классы/роли, raid markers, маршруты, маски арен, localStorage, импорт/экспорт RaidRU.
- Русские NSRT voice notes с 5-секундными предупреждениями хилерам для боссов с проверенным Heroic PTR timeline.
