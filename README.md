# RaidRU 0.2

Готовая статическая версия для GitHub Pages.

## Обновление сайта

Замените файлы в корне репозитория `NataliKh/raidru` содержимым этой папки и сделайте Commit.
GitHub Pages обновится автоматически.

## Что нового

- Главная панель рейда со всеми 8 боссами и прогрессом.
- Режим «Репетиция»: автоматическое проигрывание сцен планировщика.
- Шаблоны расстановок под конкретных боссов.
- Импорт/экспорт стратегии JSON.
- Ссылка на стратегию через URL (без сервера).
- Состав рейда: быстрый парсер списка игроков и назначение ролей.
- Генератор заметки для NSRT/рейд-чата с составом.
- Автосохранение в браузере + резервная копия.
- PWA: сайт можно установить как приложение и использовать офлайн.
- Улучшенный мобильный интерфейс и уведомления.

Версия: 0.2.0
