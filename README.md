# RaidRU 0.7.3 — Planner Palette

Главное изменение — полностью переработанная правая панель планировщика.

## Палитра
Вкладка «ОСНОВНОЕ» содержит:
- 13 классов;
- 4 роли;
- 8 рейдовых меток;
- механику карты: опасная зона, soak, стрелка, конус, линия, босс.

Вкладка «СОСТАВ» показывает реальных игроков из RaidRU roster. Их можно
перетаскивать на арену поимённо или использовать авторасстановку.

## Добавление объектов
Два режима:
- Drag & Drop — перетащить элемент палитры прямо в нужную точку карты;
- Click to Spawn — клик создаёт элемент в центре, после чего его можно двигать.

## Локальные иконки
Иконки классов, ролей и рейдовых меток находятся внутри `assets/palette/`.
Поэтому планировщик больше не зависит от hotlink на Wowhead/Warcraft Wiki.

## Дополнительные инструменты
Маршруты, масштаб/смещение/затемнение карты и расширенное редактирование
сохранены под раскрывающимся блоком «Дополнительные инструменты».
