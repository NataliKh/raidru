# RaidRU 0.7.9 — Readable Mechanic Labels

Подписи механик вынесены из самих фигур в отдельный верхний слой.

Что изменилось:
- зоны, soak, линии, стрелки и конусы остаются под игроками;
- подписи механик рисуются поверх всех токенов;
- RaidRU автоматически выбирает для подписи свободное место:
  сверху, снизу, слева или справа от механики;
- учитываются позиции игроков и уже размещённые подписи;
- подписи получили плотную тёмную плашку и цветовой индикатор типа механики;
- работает одинаково в планировщике и в проигрывателе;
- пользовательские сцены и координаты не сбрасываются.

Игровые encounter-иконки по-прежнему не имеют лишних текстовых подписей:
их название доступно при наведении.
