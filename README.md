# RaidRU 0.6

Сборка с подробными шаблонами боя и полным таймлайном на каждого босса.

## Что нового
- для каждого босса подготовлены расширенные сцены (обычно 6–8 кадров);
- для каждого босса добавлен подробный таймлайн с привязкой событий к кадрам;
- расстановка игроков и общий вектор движения сделаны более точными;
- маршруты внутри сцены и эффекты на карте предзаполнены в шаблонах;
- обновлена миграция данных: локальные сцены и таймлайн заменяются новой тактической версией 0.6, при этом сохраняются прогресс, заметки, избранное и состав.

## Важно
После обновления сайта желательно открыть его с Ctrl+F5.
Если нужен возврат к шаблону после правок — на вкладке «Редактор» есть кнопка «Шаблон босса».
