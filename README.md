# RaidRU 0.7.8 — Clean Scenario Icons

Исправлен визуальный шум в готовых сценариях планировщика.

## Изменение

Encounter-объекты на арене теперь показываются только иконкой:
- босс;
- адд;
- Колодец;
- яйцо;
- слизень;
- сгусток;
- ужас;
- щит;
- источники и другие игровые объекты.

Старые текстовые подписи `БОСС`, `КОЛОДЕЦ`, `АДД`, `ЯЙЦО` и т. п.
под иконками скрыты.

Название объекта по-прежнему доступно через tooltip при наведении мыши.

Подписи самих механик и тактических указаний (`Колодец душ`,
`Рубеж перехвата аддов`, `Soak` и т. п.) сохраняются, потому что они
объясняют происходящее в конкретном кадре.

Пользовательские координаты сцен не сбрасываются.
