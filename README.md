# RaidRU 0.7.4 — Arena Calibration

Исправлена геометрия встроенных планов относительно реальных подложек арен.

## Что сделано
- для каждого босса задана собственная игровая область, а не единый квадрат 0–100%;
- шаблоны всех сцен пересчитаны и сжаты под фактическую геометрию карты;
- точки, которые раньше попадали в яд, пустоту или за край платформы, перенесены на ближайшую доступную часть арены;
- Sentinels: обе группы перенесены внутрь прямоугольной платформы;
- Ula'tek: яйца совмещены с четырьмя площадками карты;
- Ula'tek P3: рейд больше не стоит одновременно на двух кусках разрушенной платформы — шаблон собран на одном правом нижнем сегменте;
- эффекты и маршруты шаблонов также откалиброваны;
- в планировщике появился переключатель `⌖ К арене` (по умолчанию включён): drag&drop, перемещение объектов и точки маршрута не выходят за заданную боевую площадку;
- свободное размещение можно вернуть, выключив `⌖ К арене`.

При первом запуске 0.7.4 встроенные сцены/таймлайн пересоздаются, чтобы применить новую калибровку. Прогресс, заметки, избранное и состав сохраняются.
