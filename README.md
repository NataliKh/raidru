# RaidRU 0.7.2 — Classes + Raid Markers

## Что изменилось

### Игровые raid markers
Вместо Unicode в планировщике используются публичные изображения стандартных
рейдовых меток WoW:
- Star
- Circle
- Diamond
- Triangle
- Moon
- Square
- Cross
- Skull

Источник изображений: Warcraft Wiki / Blizzard game assets.
При недоступности внешнего изображения остаётся Unicode fallback.

### Состав с классами
В состав добавлены 13 классов WoW и публичные class icons Wowhead/Zamimg.

Поддерживаются:
- Рыцарь смерти
- Охотник на демонов
- Друид
- Пробудитель
- Охотник
- Маг
- Монах
- Паладин
- Жрец
- Разбойник
- Шаман
- Чернокнижник
- Воин

Для каждого игрока хранятся:
- имя;
- класс;
- роль;
- ближний/дальний бой.

### Связь состава с планировщиком
В планировщике появился список реальных игроков из состава.

Кнопки:
- «Расставить состав на этой сцене»
- «Расставить состав во всех сценах»

Алгоритм использует расположение условных T/H/M/R токенов из тактического
шаблона как опорные кластеры и заменяет их реальными игроками.

Это означает, что игрок с классом Hunter и ролью DPS будет показан иконкой
охотника и попадёт в ranged-кластер; Rogue — в melee-кластер; танк — в
танковскую позицию и т. д.

Для гибридных классов дистанцию можно исправить вручную в составе.

### WCL Replay
Если Warcraft Logs отдаёт класс игрока (`subType`), replay тоже показывает
его class icon. При создании плана из replay класс переносится в обычный
редактируемый токен.

## Источники
- Maps/raid planning resources: RaidPlan.io
- Class icons: Wowhead / Zamimg
- Raid target markers: Warcraft Wiki / Blizzard game assets

RaidRU — неофициальный фан-проект World of Warcraft.
