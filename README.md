# RaidRU 0.7 — Warcraft Logs Replay + Planner

## Два режима

### WCL Replay
- импорт публичного отчёта Warcraft Logs по ссылке `.../reports/CODE?...&fight=ID`;
- реальные координаты игроков поверх карты арены;
- play/pause, перемотка ±1/±5 сек, скорости 0.25×–4×;
- scrubber по всему бою;
- список событий;
- просмотр всего рейда или одного игрока;
- калибровка WCL-координат: поворот, отражение, масштаб, X/Y offset;
- отдельная карта P3 для Ula'tek;
- импорт/экспорт replay JSON;
- демо-replay из тактического плана, чтобы интерфейс можно было проверить без API.

### Планировщик
Полностью сохранён режим ручного планирования из 0.6:
- реальные карты арен;
- drag&drop игроков и маркеров;
- зоны, soak, линии, конусы, стрелки;
- несколько сцен;
- маршруты игроков;
- полный таймлайн;
- просмотр плана;
- импорт/экспорт/ссылка.

### Связка двух режимов
Кнопка **«Создать план из replay»** берёт координаты игроков на событиях текущего RaidRU-таймлайна и создаёт обычные редактируемые сцены. После этого replay можно использовать как исходный материал, а стратегию править вручную.

## Warcraft Logs API
