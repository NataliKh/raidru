# RaidRU 2.0.6 — WCL New Fight

## Исправление

После загрузки WCL Replay в строке импорта появляется кнопка **«＋ Новый бой»**.

Она очищает только текущий экран Replay:
- останавливает проигрывание;
- сбрасывает время и выбранного игрока;
- удаляет текущие Replay data / URL / map state из локального состояния текущего босса;
- возвращает пустое поле WCL и сразу ставит в него фокус.

Серверный Cloudflare/WCL cache намеренно **не очищается**. Если позже открыть тот же fight, RaidRU сможет снова взять его из кэша без повторного расхода WCL API points.

Созданные ранее WCL-черновики, обычные сцены, RaidPlan-сценарии и состав не затрагиваются.
