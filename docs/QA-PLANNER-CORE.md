# Planner Core — ручная проверка alpha.2

Перед подключением RaidPlan пройди этот короткий сценарий локально.

1. Открой Планировщик на любом боссе.
2. Перетащи из палитры роль, класс и рейдовую метку на карту.
3. Добавь опасную зону и стрелку; перетащи их и измени размер/поворот через инспектор.
4. Нажми «Маршрут», добавь 3–4 точки кликами по карте, заверши маршрут и передвинь одну точку.
5. Перемести любой объект, затем проверь `Ctrl+Z` и `Ctrl+Y`.
6. Создай новую сцену, переименуй её, измени длительность, затем дублируй и удали копию.
7. Переключи Heroic → Mythic тремя способами по очереди: открыть существующий, скопировать текущий, очистить карту. Убедись, что планы сложностей независимы.
8. Перезагрузи страницу и убедись, что изменения сохранились в IndexedDB.
9. Сделай Export backup, измени план, затем Import backup и проверь восстановление.
10. Открой вкладку «Рейд» и убедись, что viewer показывает тот же план, но без редакторских контролов.

Если эти пункты проходят, Planner Core можно считать готовым к следующему этапу — RaidPlan Adapter.
