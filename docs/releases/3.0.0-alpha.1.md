# RaidRU 3.0.0-alpha.1 — Architecture Core

First clean-room web architecture based on the behavior and content of RaidRU 2.2.1.

### Included
- React + TypeScript + Vite web application.
- One version source and one React render tree.
- Eight Venomous Abyss bosses and the existing built-in tactics/scenes/timelines.
- Existing map assets preserved.
- Unified `RaidruState` + `AppStore`.
- IndexedDB persistence.
- RaidRU 2.x local-data migration adapter.
- Overview, Tactics, Raid viewer, Planner, Timeline, Roster and Notes.
- Draggable planner tokens.
- JSON backup import/export.
- WCL Worker and Chrome Bridge preserved outside the web app, not coupled to UI.
- Architecture and migration documentation.

### Intentionally deferred
- WCL integration.
- RaidPlan import.
- Full planner object palette / arrows / route authoring.
- Sharing backend.

The goal of this alpha is to establish boundaries before feature migration.
