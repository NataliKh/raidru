# RaidRU 3.0.0-alpha.2 — Planner Core

## Goal

Turn the clean alpha.1 foundation into a real raid-plan editor before any external importer is attached.

## Added

- Independent Normal / Heroic / Mythic plan storage.
- Difficulty switch dialog with three explicit behaviors: open existing, copy current, clear target map.
- Scene create, duplicate, delete and property editing.
- Palette for roles, classes, raid markers, encounter mechanics and geometry.
- Drag/drop from palette and direct object dragging on the arena.
- Selectable tokens and effects with an inspector.
- Danger/soak zones, lines and arrows with size/rotation editing.
- Routes with click-to-add points and draggable points.
- 50-step undo/redo history and keyboard shortcuts.
- Scene clearing without deleting the scene/timeline.
- Schema v4 and automatic upgrade from alpha.1 schema v3.
- Pure planner domain operations in `packages/planner-core`; AppStore now coordinates persistence/history instead of implementing geometry mutations itself.

## Architecture decisions

Planner data is owned by `AppStore`; selection and active route drawing are UI state. External importers will target the same typed scene model instead of manipulating the DOM.

## Intentionally deferred

RaidPlan and WCL are not connected in this release. The next importer must output typed `Scene[]` / `TimelineEvent[]` through a dedicated adapter and be tested against real fixtures before appearing in the UI.
