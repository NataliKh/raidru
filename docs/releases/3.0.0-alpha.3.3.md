# RaidRU 3.0.0-alpha.3.3 — Planner UX Cleanup

## Что изменилось

- Удалён переключатель `Оригинал / RaidRU` из toolbar Planner.
- Удалён связанный `presentationMode` из `PlannerWorkspace` и `Arena`.
- Импортированная RaidPlan-сцена всегда открывается в обычном редактируемом режиме RaidRU.
- Для внешней сверки остаётся ссылка `↗ RaidPlan` на исходную сцену.
- Удалены CSS-правила и validation, которые поддерживали больше не нужный режим просмотра.

Причина: отдельный режим `Оригинал` не давал самостоятельной ценности и визуально путался с импортом RaidPlan.
