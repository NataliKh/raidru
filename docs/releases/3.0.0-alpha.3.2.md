# RaidRU 3.0.0-alpha.3.2 — RaidPlan Native Tokens

Точечный релиз визуальной совместимости после сравнения оригинального RaidPlan и RaidRU.

## Причина

RaidPlan `marker`/`mob` обычно не содержит `opacity`. Adapter корректно сохранял отсутствие opacity как `null`, но React renderer делал `Number(null)` и получал `0`. В результате все native role/raid-marker/mob tokens становились полностью прозрачными. Текст и векторы при этом отображались, поэтому импорт выглядел как «только текст + стрелка».

## Исправлено

- optional visual metadata теперь разбирается null-safe helper-ом: отсутствие opacity не создаёт CSS `opacity: 0`;
- явный `opacity: 0` по-прежнему остаётся скрытым;
- native token style вынесен в отдельный тестируемый модуль `nativeTokenStyle.ts`;
- `encounter` и `mechanic` получили отдельные CSS-классы вместо случайного fallback в `marker`;
- `mob.lname` рассматривается как внутреннее/tooltip имя, а не как обязательная подпись на карте; подпись рисуется только при реальном `attr.text`;
- для mob сохраняются `ringSize`, `ringOffset`, `face`, `noDir` для следующего этапа точного рендера направления.

## Regression

Scene 1 fixture содержит RaidPlan role/raid marker без opacity. Проверка теперь подтверждает одновременно:

1. domain model хранит `opacity: null`;
2. UI style не содержит `opacity` для такого token;
3. explicit `opacity: 0` остаётся нулём.

Worker не менялся, redeploy Cloudflare для alpha.3.2 не требуется.
