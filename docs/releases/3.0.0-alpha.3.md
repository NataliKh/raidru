# RaidRU 3.0.0-alpha.3 — RaidPlan Adapter

## Цель релиза

Подключить RaidPlan к новой архитектуре RaidRU 3 без возврата к legacy-подходу, где importer напрямую изменял DOM или внутреннее состояние UI.

Pipeline:

```text
RaidPlan URL / JSON
  ↓
RaidPlanClient (transport only)
  ↓
@raidru/raidplan-core
  ↓
RaidPlan v2 strict visible conversion
  ↓
BossDifficultyPlanState
  ↓
AppStore.applyExternalPlan()
  ↓
Planner / Viewer
```

## Что реализовано

- новый чистый TypeScript adapter `packages/raidplan-core`;
- распознавание v2 `nodes + meta.step`;
- robust root discovery для обёрнутых payload;
- strict whitelist для видимых типов;
- `hidden`, `visible:false`, `opacity:0`, `scale:0`, helper/mask nodes отбрасываются;
- map-backed `arena` используется как background, а не как зона поверх карты;
- canvas RaidPlan v2 сохраняется как fixed `1200×675` (или явно заявленный canvas);
- роли и raid markers импортируются по asset;
- `itext` остаётся текстом;
- `sourceOrder` сохраняется и используется для interleaved z-order native vectors/tokens;
- freehand `path.attr.points` сохраняет stroke-only геометрию;
- Fabric `line.attr.points` распознаёт endpoint signature и сохраняет off-canvas части;
- импортированные сцены можно безопасно **добавить** либо явно **заменить** текущий план;
- перед применением importer показывает preview/report;
- Store re-key импортированных сущностей предотвращает collision при повторном импорте;
- URL-import использует `/raidplan` Worker; Worker сначала ищет точный revisioned `userdata` URL на странице плана и только затем использует code fallback; raw JSON можно открыть локально;
- Vite dev/preview origins разрешены в Worker для локального тестирования.

## Regression fixtures

В `tests/fixtures/raidplan/` перенесены проверенные материалы старой ветки:

- `scene3-paths.json` — high-resolution freehand arrows;
- `scene4-lines.json` — Fabric drawn lines около `(0,0)`;
- `offcanvas-vector.md` — документированное правило off-canvas clipping.

`npm test` проверяет не наличие строк, а результат pure converter:

- degenerate path отбрасывается;
- остальные path остаются stroke-only;
- canvas остаётся `1200×675`;
- Nek'zali остаётся примерно `(50%, 51%)`;
- три drawn line сохраняют отрицательные координаты и не clamp-ятся;
- неизвестный v2 node не превращается в случайную zone;
- map-backed arena не попадает в `scene.effects`.

## Не входит в alpha.3

- WCL Replay;
- автоматическое сравнение скриншота RaidPlan и RaidRU;
- редактирование всех специфических типов RaidPlan один-в-один;
- публикация нового Worker автоматически из web build.

Это намеренно: задача alpha.3 — стабильный boundary между внешним форматом RaidPlan и доменной моделью RaidRU.
