# RaidRU 3.0.0-alpha.3.1 — RaidPlan Visual Fidelity

Промежуточный релиз перед Replay Core. Цель — довести отображение импортированного RaidPlan до стабильной визуальной модели.

## Исправлено

- локальные palette assets теперь разрешаются через `import.meta.env.BASE_URL`, поэтому GitHub Pages `/raidru/` и Vite dev используют один путь;
- импортированные role/raid markers используют исходный RaidPlan CDN asset с локальным fallback;
- IText сохраняет `fontSize`, `scale`, `lineHeight`, `fontFamily`, `fontWeight`, `charSpacing`, rotation и Fabric origin;
- z-order учитывает explicit `zIndex/z` и только затем source order;
- helper/guide/debug IText отбрасываются, дубли текста в одной точке дедуплицируются;
- у каждой RaidPlan-сцены сохраняется provenance: code, revision, source URL и номер сцены;
- в Planner добавлены режимы `Оригинал` / `RaidRU`, ссылка на исходную сцену RaidPlan и fidelity strip;
- Scene note явно отделена от canvas-текста, чтобы заметка не воспринималась как лишний объект.

## Регрессии

Зафиксированы реальные геометрические случаи плана `9v3wssyjja56rttz`: Scene 3 freehand paths и Scene 4 off-canvas Fabric lines. Добавлен Scene 1 typography/roles fixture и проверки deployment-safe asset resolution contracts.
