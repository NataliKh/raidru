# RaidRU 2.0.11 — Mechanics Readability

UI-only readability pass for WCL Mechanics Analysis.

## Changes
- Increased Mechanics Analysis typography from the old 7–10 px dense layout to readable 10–15 px supporting text and 24 px section heading.
- Increased WCL metrics, filters, actions and replay tabs.
- Timeline lanes are taller; lane labels, time ruler and event markers are larger.
- Timeline hover labels are larger and easier to read.
- Mechanic cards and expanded occurrence rows use larger text and spacing.
- Below 1200 px the mechanic list becomes one column instead of squeezing two cards.
- No WCL API, Worker, cache, rate-limit, coordinate or RaidPlan import logic changed.
