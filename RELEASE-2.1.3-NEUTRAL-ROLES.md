# RaidRU 2.1.3 — Neutral Roles

## Изменения

- Удалена отдельная кнопка **«Холи-прист»** из шапки.
- Удалён специализационный переключатель и его состояние из localStorage.
- Подсказки по лечению теперь показываются универсальной карточкой **«Хилы»**.
- Обычная рейдовая заметка использует секцию **«Хилы»**, а не одну конкретную специализацию.
- Словарь больше не добавляет отдельный набор способностей Holy Priest.
- Три оставшиеся специализационные формулировки в тактиках обобщены для всех хилеров.
- Классовый объект `priest` в составе/палитре не удалялся: жрец остаётся обычным поддерживаемым классом.
- WCL, RaidPlan, Replay, Mechanics Analysis и Performance Core не менялись.

## Совместимость

Старое поле `priestMode` автоматически удаляется из загруженного состояния и больше не сохраняется.
