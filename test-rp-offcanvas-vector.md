# Regression: off-canvas RaidPlan vectors

Эталон: `https://raidplan.io/plan/9v3wssyjja56rttz#4`.

На сцене 4 белая рисованная стрелка почти полностью находится за верхней левой
границей карты. В RaidRU допустимо видеть только ту часть, которая попадает в
viewport. Импортёр не должен clamp/snap-ить центр `path`/`line` к 0.5–99.5%.

Проверка после импорта:
- стрелка не переносится целиком внутрь карты;
- видимый фрагмент остаётся у верхнего левого края;
- сцена 3 по-прежнему показывает две полноценные freehand-стрелки.
