# Arena backgrounds

Фоновые изображения арен экспортированы пользователем через функцию
**Download image** в RaidPlan для рейда The Venomous Abyss.

Использование в RaidRU сопровождается атрибуцией:
`Maps/raid planning resources: RaidPlan.io`

Файлы оптимизированы в WebP без изменения исходного соотношения сторон 1231×692.
