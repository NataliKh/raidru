# RaidRU 1.0.1 — UI polish

Цель патча — приблизить реальный интерфейс к утверждённому визуальному направлению RaidRU 1.0, не затрагивая геометрию RaidPlan-импорта и canvas планировщика.

## Новая шапка

- Основная навигация собрана в единый компактный блок: Обзор, Тактика, Рейд, Планировщик, Таймлайн, Состав, Заметки.
- Второстепенные разделы (`Мои планы`, `План: просмотр`, `Словарь` и другие добавочные режимы) перенесены в меню `•••`.
- RaidPlan, специализация, Поделиться, Экспорт и Импорт отделены как utility actions.
- Автосохранение больше не показывает длинное имя плана в шапке: только компактный статус `Сохранено`.
- Активный раздел обозначается тонкой зелёной линией вместо тяжёлой заливки.

## Новый визуальный таймлайн

Старый ряд маленьких точек заменён дорожками:

1. Урон рейду
2. Перемещение
3. Механика танка
4. Адды
5. Назначения / КД
6. Назначения

Особенности:

- читаемая временная линейка;
- карточки событий с названием и временем;
- автоматическое разнесение близких событий на поддорожки, чтобы подписи не накладывались;
- цветовая кодировка механик;
- вертикальный playhead выбранного события;
- один клик выбирает событие и подсвечивает строку редактора;
- двойной клик открывает связанный кадр в проигрывателе;
- режимы `Линии` и `Сжатый вид`;
- назначения выводятся отдельной зелёной дорожкой и ведут в редактор назначений.

## Совместимость

Патч не меняет:

- RaidPlan importer и его геометрию;
- структуру сцен;
- формат `timelineV3`;
- WCL replay JSON;
- данные Workspace и историю;
- planner canvas.

Новый UI хранит только локальные настройки отображения в `state._ui101`.
