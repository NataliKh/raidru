# RaidRU 1.0 — Raid Ready

Версия 1.0 переводит RaidRU из режима «редактор тактики» в полный цикл подготовки рейдового плана: **создать → проверить → зафиксировать → провести бой → скорректировать**.

## Главное

### Проверка готовности
Новая страница «Готовность» автоматически проверяет:
- состав и наличие двух танков/хилов;
- ключевые сцены и пустые кадры;
- заполненность сценария объяснения;
- таймлайн и его привязку к сценам;
- объекты, вышедшие за координаты арены;
- персональные назначения;
- хил-КД;
- итоговую рейдовую заметку.

RaidRU показывает общий процент готовности и ведёт прямо в раздел, который нужно исправить.

### Режим «Рейд»
Новый боевой экран предназначен для объяснения тактики на втором мониторе или через Discord:
- крупная карта текущей сцены;
- действия рейда, танков и хилов;
- назначения текущего кадра;
- следующие механики;
- репетиция боя с автоматическим переходом по таймлайну;
- полноэкранный режим.

### Сценарий сцены
У каждой сцены теперь можно хранить четыре отдельных инструкции:
- весь рейд;
- танки;
- хилы;
- короткая голосовая команда РЛ/TTS.

Эти поля используются в режиме «Рейд» и при генерации персонального плана.

### «Мой план»
RaidRU собирает для выбранного игрока персональную ленту из:
- общих действий сцены;
- ролевых действий;
- персональных назначений;
- таймингов.

План можно скопировать обычным текстом или как персональный NSRT Reminder import для боссов с известным EncounterID.

### Снимки перед рейдом
В Workspace появилась явная кнопка «Снимок».
Снимок хранит сцены, таймлайн, состав и назначения. История 1.0 умеет сравнивать снимок с текущей версией по основным изменениям перед восстановлением.

## Совместимость

- Данные 0.9.5 продолжают использовать тот же `localStorage` (`raidru-standalone`).
- Raid Workspace 0.9.5 не удаляется: 1.0 расширяет его отдельным модулем `raid-ready-100.js`.
- Геометрия и конвертация RaidPlan не менялись, чтобы не возвращать исправленные ранее регрессии импорта.
- WCL Draft остаётся доступным.

## Файлы 1.0

Новые/изменённые основные файлы:
- `raid-ready-100.js` — функции Raid Ready;
- `styles.css` — интерфейс 1.0;
- `index.html` — подключение версии 1.0;
- `sw.js` — новый cache key;
- `manifest.webmanifest` — метаданные релиза.
