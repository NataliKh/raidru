# RaidRU 2.1.2 — Plan Viewer

Исправление страницы **План: просмотр** для длинных таймлайнов.

## Что изменено

- карта/сцена закрепляется при прокрутке на desktop;
- таймлайн справа получил собственную прокрутку и больше не растягивает всю страницу;
- прокрутка колесом внутри таймлайна не уводит всю страницу (`overscroll-behavior`);
- заголовок таймлайна закреплён внутри панели;
- после смены кадра активное событие автоматически оказывается в видимой части таймлайна;
- на узких экранах sticky-режим отключается и сохраняется обычная одноколоночная компоновка;
- данные таймлайна не урезаются и не группируются: меняется только навигация по ним.

Worker/WCL/RaidPlan pipeline не менялись.
